# لغة عربية (Arabic Programming Language)

لغة برمجة عربية بسيطة، تُكتب **فقط بالكلمات العربية والأرقام** (`0`-`9`،
مع السماح بنقطة عشرية واحدة داخل العدد مثل `1.8`). لا توجد أي رموز أخرى في
الشيفرة المصدرية: لا أقواس، لا علامات اقتباس، لا عوامل رياضية مكتوبة برموز
(`+ - * / = < >`)، ولا فواصل منقوطة. كل شيء يُكتب ككلمات عربية.

مثال:

```
اطبع نص مرحبا بالعالم
ادخل ا
اطبع قيمة ا
اذا ا اكبر من او يساوي 10
بداية
اطبع نص انه كبير
نهاية
```

## التشغيل

يحتاج المفسّر Python 3 فقط، بدون أي تبعيات خارجية.

```bash
python3 run.py examples/مرحبا.arabic
```

أو شغّل الوضع التفاعلي (REPL) بدون تمرير ملف: اكتب أوامرك سطرًا سطرًا ثم
اضغط Enter على سطر فارغ لتنفيذها (وتُحفظ المتغيرات بين الأوامر):

```bash
python3 run.py
```

أو من كود Python مباشرة:

```python
from arabic_lang import شغّل_نص

شغّل_نص("اطبع نص مرحبا بالعالم")
```

## قواعد الكتابة العامة

- كل جملة في سطر مستقل.
- الكلمات تُفصل بمسافات فقط.
- الأعداد تُكتب بالأرقام `0123456789`، مع نقطة عشرية اختيارية واحدة (مثل `1.8`).
- أسماء المتغيرات والدوال: أي كلمة عربية ليست من الكلمات المحجوزة (بدون شرطة سفلية أو أي رمز).
- الأسطر الفارغة تُتجاهل.
- التعليقات: كلمة `ملاحظة` تبدأ تعليقًا حتى نهاية السطر، سواء في بداية السطر أو بعد كود فعلي.
- كل كتلة (شرط/حلقة/دالة/حاول) تُفتح بكلمة `بداية` في سطر مستقل، وتُغلق بكلمة `نهاية` في سطر مستقل.

## جدول الكلمات المحجوزة

| الكلمة | المعنى |
|---|---|
| `اطبع` | طباعة |
| `نص` | يشير إلى أن ما بعده نص حرفي حتى نهاية السطر |
| `قيمة` | يشير إلى أن ما بعده تعبير يجب تقييمه وطباعة قيمته |
| `ادخل` | قراءة سطر من المستخدم وتخزينه في متغير |
| `اجعل` | إسناد قيمة إلى متغير |
| `يساوي` | يُستخدم في الإسناد (`اجعل`) وفي المقارنة (`==`) |
| `اذا` | جملة شرطية |
| `والا` | التفرّع الآخر (يمكن أن تُتبع بـ `اذا` لعمل `والا اذا`) |
| `طالما` | حلقة تكرار شرطية (while) |
| `كرر` ... `من` ... `الى` ... `بخطوة` | حلقة تكرار عددية (for) |
| `بداية` / `نهاية` | فتح/إغلاق كتلة |
| `دالة` / `معطيات` | تعريف دالة ومعطياتها |
| `ارجع` | إرجاع قيمة من دالة |
| `نداء` | نداء دالة (كتعبير أو كجملة مستقلة) |
| `توقف` | كسر الحلقة الحالية (break) |
| `استمر` | الانتقال للتكرار التالي (continue) |
| `ملاحظة` | تعليق (يُتجاهل السطر بالكامل) |
| `زائد` `ناقص` `في` `على` `باقي` | + - × ÷ % |
| `اكبر من` `اصغر من` `يساوي` `لا يساوي` `اكبر من او يساوي` `اصغر من او يساوي` | > < == != >= <= |
| `و` `او` `ليس` | AND / OR / NOT (و`او` تُستخدم أيضًا للفصل بين معطيات نداء دالة متعددة) |
| `صح` `خطأ` `فارغ` | true / false / none |
| `سالب` | نفي عدد (سالب 5 = -5) |
| `قائمة` | إنشاء قائمة (مصفوفة) |
| `عنصر` ... `من` | قراءة عنصر من قائمة برقم ترتيبه (يبدأ من 1) |
| `طول` | طول نص أو قائمة |
| `اضف` ... `الى` | إضافة قيمة لنهاية قائمة |
| `لكل` ... `ضمن` | حلقة تكرار على عناصر قائمة (foreach) |
| `زد` / `انقص` ... `مقدار` | زيادة/إنقاص متغير (بمقدار 1 افتراضيًا) |
| `اجعل عام` | إسناد إلى متغير عام من داخل دالة |
| `حاول` / `امسك` | معالجة الأخطاء (try/catch) |

## الجمل التفصيلية

### الطباعة

```
اطبع نص مرحبا بالعالم        ملاحظة يطبع النص الحرفي كما هو
اطبع قيمة ا                  ملاحظة يطبع قيمة المتغير أو التعبير
اطبع قيمة 2 زائد 3 في 4      ملاحظة يطبع نتيجة التعبير الحسابي
```

### الإدخال والمتغيرات

```
ادخل ا                       ملاحظة يقرأ سطرًا من المستخدم ويضعه في المتغير ا
اجعل العمر يساوي 20          ملاحظة إسناد قيمة مباشرة
اجعل الاجمالي يساوي السعر في الكمية
```

القيمة المُدخلة تُحوَّل تلقائيًا إلى عدد إن أمكن (بما فيها الأعداد
العشرية مثل `1.8`)، وإلا تبقى نصًا.

### الشرط

```
اذا العمر اكبر من او يساوي 18
بداية
اطبع نص بالغ
نهاية
والا
بداية
اطبع نص قاصر
نهاية
```

سلسلة `والا اذا` مدعومة:

```
اذا الدرجة اكبر من او يساوي 90
بداية
اطبع نص ممتاز
نهاية
والا اذا الدرجة اكبر من او يساوي 60
بداية
اطبع نص جيد
نهاية
والا
بداية
اطبع نص راسب
نهاية
```

### حلقة طالما (while)

```
اجعل العداد يساوي 5
طالما العداد اكبر من 0
بداية
اطبع قيمة العداد
اجعل العداد يساوي العداد ناقص 1
نهاية
```

### حلقة كرر (for)

```
كرر ن من 1 الى 10
بداية
اطبع قيمة ن
نهاية
```

مع خطوة اختيارية (الخطوة الافتراضية `1`، أو `-1` تلقائيًا إذا كانت
النهاية أصغر من البداية):

```
كرر ن من 10 الى 0 بخطوة 0 ناقص 2
بداية
اطبع قيمة ن
نهاية
```

### توقف واستمر

```
كرر ن من 1 الى 10
بداية
اذا ن يساوي 3
بداية
استمر
نهاية
اذا ن يساوي 7
بداية
توقف
نهاية
اطبع قيمة ن
نهاية
```

### الدوال

```
دالة اجمع معطيات س ص
بداية
ارجع س زائد ص
نهاية

اجعل الناتج يساوي نداء اجمع 7 و 5
اطبع قيمة الناتج
```

- تُعرَّف المعطيات بعد كلمة `معطيات` (يمكن الاستغناء عنها لدالة بلا معطيات).
- عند نداء دالة بأكثر من معطى واحد، يجب الفصل بين المعطيات بكلمة `و`.
- كل معطى يمكن أن يكون تعبيرًا حسابيًا كاملًا (مثل `ن ناقص 1`)، لكن لا
  يمكن نداء دالة أخرى داخل معطى (لا نداءات متداخلة).
- الدوال تدعم الاستدعاء الذاتي (recursion):

```
دالة فيب معطيات ن
بداية
اذا ن اصغر من او يساوي 1
بداية
ارجع ن
نهاية
اجعل أ يساوي نداء فيب ن ناقص 1
اجعل ب يساوي نداء فيب ن ناقص 2
ارجع أ زائد ب
نهاية
```

- يمكن نداء الدالة كجملة مستقلة (بدون استخدام قيمتها المُرجعة):

```
نداء رحب نص سارة
```

### النصوص

`نص` تجعل كل ما تبقى في السطر (أو في التعبير) نصًا حرفيًا حتى نهايته —
لذلك لا يمكن أن يتبعها `زائد` داخل نفس الاستخدام. لدمج نص مع متغير، خزّن
النص في متغير أولًا ثم اجمع المتغيرات بـ `زائد`:

```
اجعل الاسم يساوي نص احمد
اجعل الرسالة يساوي نص مرحبا يا
اطبع قيمة الرسالة زائد الاسم
```

جمع نصين بـ `زائد` يضع مسافة واحدة بينهما تلقائيًا (الناتج: `مرحبا يا احمد`).

### المنطق

```
اذا العمر اكبر من او يساوي 18 و مرخص يساوي صح
بداية
اطبع نص يمكنه القيادة
نهاية
```

`و`، `او`، `ليس` تعمل كعوامل منطقية اعتيادية (مع تقييم قصير-الدائرة
short-circuit لـ `و` و `او`).

### الأعداد السالبة

بما أن إشارة `-` غير مسموحة كرمز، يُستخدم `سالب` كعامل أحادي:

```
اطبع قيمة سالب 5          ملاحظة يطبع -5
اطبع قيمة 10 زائد سالب 3  ملاحظة يطبع 7
```

### زد وانقص

اختصار لزيادة/إنقاص متغير دون إعادة كتابة الإسناد كاملًا:

```
اجعل ن يساوي 10
زد ن                 ملاحظة ن = 11
زد ن مقدار 5          ملاحظة ن = 16
انقص ن مقدار 3         ملاحظة ن = 13
```

### القوائم (المصفوفات)

```
اجعل القائمة يساوي قائمة 10 و 20 و 30
اطبع قيمة طول القائمة          ملاحظة 3
اطبع قيمة عنصر 1 من القائمة     ملاحظة 10 (الترقيم يبدأ من 1)
اجعل عنصر 2 من القائمة يساوي 99 ملاحظة تعديل عنصر
اضف 40 الى القائمة              ملاحظة إضافة عنصر جديد في النهاية

لكل عدد ضمن القائمة
بداية
اطبع قيمة عدد
نهاية
```

- القائمة الفارغة: `اجعل القائمة يساوي قائمة` (بدون عناصر بعدها).
- عناصر `قائمة` تُفصل بكلمة `و`، وكل عنصر يمكن أن يكون تعبيرًا حسابيًا،
  لكن لا يمكن نداء دالة داخل عنصر قائمة (نفس قيد معطيات الدوال).
- الفهرس في `عنصر <فهرس> من <قائمة>` و`اجعل عنصر ... من ... يساوي ...`
  يجب أن يكون قيمة مباشرة (رقم أو متغير)، وليس تعبيرًا مركبًا.

### معالجة الأخطاء (حاول/امسك)

```
حاول
بداية
اطبع قيمة 1 على 0
نهاية
امسك رسالة
بداية
اطبع نص حدث خطأ
اطبع قيمة رسالة
نهاية
```

اسم المتغير بعد `امسك` اختياري؛ إن وُجد يحتوي على نص رسالة الخطأ. أي
خطأ أثناء التشغيل داخل `حاول` (قسمة على صفر، متغير غير معرف، فهرس خارج
الحدود...) يُمسك بدل إيقاف البرنامج بالكامل.

### الدوال الرياضية المدمجة

تُستدعى مثل أي دالة عادية بكلمة `نداء`:

```
اطبع قيمة نداء جذر 16              ملاحظة 4
اطبع قيمة نداء مطلق سالب 7          ملاحظة 7
اطبع قيمة نداء قوة 2 و 10           ملاحظة 1024
اطبع قيمة نداء أعظم 3 و 9 و 5       ملاحظة 9 (تقبل أعدادًا متعددة أو قائمة واحدة)
اطبع قيمة نداء أصغر 3 و 9 و 5       ملاحظة 3
اطبع قيمة نداء عشوائي 1 و 10        ملاحظة عدد صحيح عشوائي بين 1 و10
```

### متغير عام من داخل دالة

الدالة تقرأ المتغيرات العامة تلقائيًا لكن لا تستطيع تعديلها إلا بـ `اجعل عام`:

```
اجعل العداد يساوي 0
دالة زدالعداد
بداية
اجعل عام العداد يساوي العداد زائد 1
نهاية
نداء زدالعداد
نداء زدالعداد
اطبع قيمة العداد    ملاحظة 2
```

## أمثلة كاملة

راجع مجلد [`examples/`](examples/):

- `مرحبا.arabic` — المثال الأساسي (طباعة، إدخال، شرط).
- `جدول_الضرب.arabic` — حلقة `كرر`.
- `حلقة_طالما.arabic` — حلقة `طالما` وأعداد عشرية.
- `دوال.arabic` — تعريف واستدعاء الدوال.
- `فيبوناتشي.arabic` — دالة تكرارية (recursion).
- `منطق_وحلقات.arabic` — `و`/`او`/`ليس`، سلسلة `والا اذا`، `توقف`/`استمر`.
- `قوائم_وميزات_جديدة.arabic` — القوائم، `لكل`، `زد`، `حاول`/`امسك`، والدوال المدمجة.
